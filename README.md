## ✨ О проекте

**TwitchStream** — небольшое приложение на Python, которое позволяет смотреть Twitch-трансляции прямо из отдельного GUI.

Больше не нужно каждый раз открывать браузер, заходить на Twitch и искать нужный канал.

Запускаешь приложение → нажимаешь **«Запустить»** → смотришь трансляцию.

Видео выводится непосредственно внутри приложения.

# 🚀 Возможности

### 🎬 Встроенный видеоплеер

Смотрите Twitch прямо внутри приложения.

Не требуется открывать Twitch в браузере.

### ▶️ Запуск трансляции

Одна кнопка:

**▶ Запустить**

Приложение автоматически получает поток через Streamlink и передаёт его в видеоплеер.

### 🔄 Перезапуск

Кнопка:

**↻ Перезапустить**

заново получает поток и перезапускает воспроизведение.

### ⏹️ Остановка

Кнопка:

**■ Остановить**

полностью прекращает воспроизведение.

### 🔊 Управление громкостью

В приложении присутствует:

* 🔊 регулировка громкости;
* 🔇 отключение звука;
* 🎚️ ползунок громкости;
* отображение текущей громкости в процентах.

### 🔁 Автопереподключение

Если соединение с трансляцией потеряно, приложение может автоматически попробовать подключиться снова.

### 👁 Счётчик зрителей

При настройке Twitch API приложение может отображать текущее количество зрителей трансляции.

Например:

```text
👁 Зрители: 1 245
```

### 📺 Без Twitch-интерфейса

Приложение показывает непосредственно видеопоток.

Никаких:

* рекомендаций;
* чата;
* рекламы сайта;
* главной страницы Twitch;
* лишних элементов интерфейса.

Только трансляция и управление.

```bash
git clone https://github.com/YOUR_USERNAME/TwitchStream.git
cd TwitchStream
```

## 2. Установка зависимостей

```bash
python -m pip install PySide6 streamlink requests
```


# ▶️ Запуск

Запустите:

```bash
python main.py
```

После открытия GUI:

1. Нажмите **▶ Запустить**
2. Подождите получение потока
3. Трансляция появится в видеоплеере
4. Для повторного подключения используйте **↻ Перезапустить**
5. Для остановки нажмите **■ Остановить**

---

# ⚙️ Настройка канала

В `main.py` найдите:

```python
TWITCH_URL = "https://www.twitch.tv/pwgood"
```

И замените URL на нужный Twitch-канал:

```python
TWITCH_URL = "https://www.twitch.tv/CHANNEL_NAME"
```

Например:

```python
TWITCH_URL = "https://www.twitch.tv/xqc"
```

После этого приложение будет использовать указанный канал.

# 👁 Twitch API

Для отображения количества зрителей необходимо указать Twitch Client ID и Access Token.

В коде:

```python
TWITCH_CLIENT_ID = ""
TWITCH_ACCESS_TOKEN = ""
```

Укажите:

```python
TWITCH_CLIENT_ID = "YOUR_CLIENT_ID"
TWITCH_ACCESS_TOKEN = "YOUR_ACCESS_TOKEN"
```

Если оставить значения пустыми, сам видеоплеер продолжит работать, однако количество зрителей отображаться не будет.

> ⚠️ Не публикуйте `TWITCH_ACCESS_TOKEN` в GitHub.

Если токен случайно попал в публичный репозиторий — его следует немедленно отозвать.

# 🧵 Многопоточность

Получение Twitch-потока и запросы к Twitch API выполняются в отдельных `QThread`.

Это позволяет GUI оставаться отзывчивым во время:

* получения потока;
* API-запросов;
* переподключения;
* обновления количества зрителей.

Таким образом, интерфейс не должен зависать при выполнении сетевых операций.

---

# 🔐 Безопасность

Не рекомендуется хранить Twitch Access Token непосредственно в исходном коде, если репозиторий является публичным.

Лучше использовать переменные окружения:

```python
import os

TWITCH_CLIENT_ID = os.getenv("TWITCH_CLIENT_ID", "")
TWITCH_ACCESS_TOKEN = os.getenv("TWITCH_ACCESS_TOKEN", "")
```

Например, в Windows:

```cmd
set TWITCH_CLIENT_ID=YOUR_CLIENT_ID
set TWITCH_ACCESS_TOKEN=YOUR_ACCESS_TOKEN
```

# 🐛 Известные особенности

Поскольку приложение получает поток через Streamlink, работоспособность зависит от текущей доступности Twitch и поддержки Twitch со стороны Streamlink.

Если канал оффлайн, приложение не сможет получить видеопоток.

При временном разрыве соединения используется автоматическое переподключение.
